# Установка

Меняем устройство с которого загружаемся на флешку с заранее подготовленной системой **(ЧИСТОЙ) (НЕ СБОРКА)**

В установщике тыкаем всё далее, до того момента когда нужно выбрать издание системы
>Ремарка

(Если установка началась просто так, то можно справиться generic ключами) 

Generic ключи:

| Редакция              | Ключ                          |
| --------------------- | ----------------------------- |
| Windows 11 Home       | YTMG3-N6DKC-DKB77-7M9GH-8HVX7 |
| Windows 11 Pro        | VK7JG-NPHTM-C97JM-9MPGT-3V66T |
| Windows 11 Enterprise | XGVPP-NMH47-7TTHJ-W3FW7-8HV2C |
| Windows 11 Education  | YNMGQ-8RYV3-4PGQ3-C8XTP-7CFBY |

##### 

Выбираем **ОБЯЗАТЕЛЬНО** редакцию Pro

Подтираем разделы с прошлой системой <font style="color:grey">*(если такая была)*</font> 
И устанавливаем систему

Проходим первоначальную настройку, до момента подключения к сети. После чего нажимаем `Shift` + `F10` и вводим в `OOBE\BYPASSNRO` 

Проходим ещё раз... 😊. В том моменте, когда будет настройка сети появится пункт "У меня нет интернета" после этого мы ещё раз посылаем Microsoft со словами "Продолжить ограниченную установку". И создаём <font style="color:grey">*слава богу*</font> локальную учётку. Лучше пока-что пароль не ставить, мы сделаем это позже.
На следующем пункте: "Выберете параметры конфиденциальности". Нам нужно отключить **ВСЁ НАХУЙ!**

После попадания на рабочий стол отрубаем тумблерами Defender и ставим Windows Update на паузу чтобы не мешал ставить более новые драйвера. Будем скачивать через офф сайт производителя, а уже потом, если ничего не найдётся, то через Snappy Driver Installer.
